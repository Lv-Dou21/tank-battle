# 🎮 坦克大战 Tank Battle

经典红白机坦克大战的 HTML5 复刻版！纯前端实现，无需安装任何依赖，打开即玩。

## 🚀 在线试玩

直接用浏览器打开 [`index.html`](index.html) 即可，或者部署到 GitHub Pages 访问。

## 🕹️ 操作方式

| 按键 | 功能 |
|------|------|
| `W` / `A` / `S` / `D` 或 **方向键** | 移动坦克 |
| `空格键 Space` | 射击 |
| `P` | 暂停 / 继续 |
| `R` | 重新开始 |

## ✨ 功能特性

- 🏰 **多关卡地图**：砖墙、钢板、水域、草丛等丰富地形
- 🤖 **智能敌人 AI**：敌坦克自动追踪、转向、射击
- 💥 **粒子特效**：爆炸、碎片特效，真实反馈
- ❤️ **生命与重生系统**：拥有 3 条命，复活时短暂无敌
- 📈 **计分系统**：摧毁敌坦克得分，全歼即通关
- ⚔️ **基地防守**：保护你的红色宝库不被摧毁

## 🧱 地形说明

| 地形 | 说明 |
|------|------|
| 🧱 红砖 | 可被子弹摧毁 |
| ⬜ 钢板 | 不可摧毁（抵挡子弹） |
| 🌊 水域 | 坦克无法通过 |
| 🌿 草丛 | 装饰地形，可通行 |
| ❤️ 基地 | 被击中即游戏失败 |

## 🛠️ 技术实现

- 纯原生 JavaScript，无任何第三方库
- Canvas 2D 渲染，60 FPS 游戏循环
- 基于格子(Tile)的地图与碰撞检测系统
- 采用经典 13×13 网格地图尺寸
